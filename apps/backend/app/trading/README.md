# `app/trading` — Цикл бота, order manager, машина станів ордера

## Призначення

Статуси бота, цикл на закритті свічки, машина станів ордера (граф ТЗ §7.1, write-ahead `SUBMITTING`), розв'язання `SUBMISSION_UNKNOWN`, fills і облік капіталу, входи/виходи, перемикання моделі.

> Заплановано: T3.1, T3.3, T3.4, T5.1, T5.2, T5.3, T5.4. Зараз пакет порожній (каркас T0.1).

- ТЗ §7 — машина станів ордера та ідемпотентність
