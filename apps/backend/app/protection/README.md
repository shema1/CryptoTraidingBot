# `app/protection` — Position Protection Manager

## Призначення

Гарантує біржовий SL для кожної позиції: нативні TP/SL, fallback `set_position_protection`, стан `ENTRY_FILLED_UNPROTECTED` з примусовим закриттям після `protection_timeout_s`.

> Заплановано: T4.3. Зараз пакет порожній (каркас T0.1).
