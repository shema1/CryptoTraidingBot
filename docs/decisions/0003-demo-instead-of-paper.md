# 0003. Bybit Demo Trading замість власного Paper-симулятора

- **Дата:** 2026-10-28
- **Статус:** прийнято (підтверджено власником проєкту)
- **Зачеплені розділи ТЗ:** §3, §5.2.2, §5.3, §5.4, §5.4.1, §5.7, §5А.3, §5А.10, §8.1, §13, §14, §16, §16А.3, §17, §19
- **Зачеплені задачі:** T5.5 видалено; T3.6, T3.7, T5.11, T5.8, T6.2 оновлено

## Контекст

ТЗ передбачало режим Paper: власний `PaperExchangeAdapter`, що симулює виконання ордерів на живих цінах (спред, затримка, SL/TP за mark price). Це окремий адаптер із власними помилками, який лише імітує біржу. Bybit має Demo Trading: окремий демо-акаунт із віртуальними коштами, справжнім API (`api-demo.bybit.com`, приватний WS `stream-demo.bybit.com`) і публічними даними, такими самими, як на mainnet. Demo підтримує ордери, trading-stop (SL/TP), позиції, execution list і приватні потоки order / execution / position / wallet.

## Рішення

| Було | Стало |
|---|---|
| Режими Paper / Testnet / Live | Режими **Demo** / Testnet / Live |
| Власний `PaperExchangeAdapter` (симуляція виконання) | Немає; Demo використовує той самий адаптер Bybit, що й live — відрізняються лише адреси та ключі |
| Paper-прогін (T5.11) на симуляції | Demo-прогін на реальних цінах і реальному API |
| Нова модель 2 тижні в Paper/Testnet паралельно з діючою | 2 тижні в Demo |
| Ключі для Testnet і Live | Ключі для Demo, Testnet і Live (`BYBIT_DEMO_API_KEY/SECRET`) |

Без змін: Testnet лишається обов'язковим для chaos-сценаріїв і 7-денного прогону перед Live; `FakeExchangeAdapter` з ін'єкцією збоїв лишається для автотестів.

## Наслідки

- Мінус задача T5.5 (R2) і цілий адаптер із симуляцією виконання.
- Поведінка ордерів і SL у Demo — справжня поведінка біржі, а не власна модель.
- Обмеження Demo: ордери зберігаються 7 днів; не всі ендпоінти доступні. Доступність потрібних ендпоінтів перевіряється в T3.7; якщо чогось бракує — відповідна перевірка переноситься на Testnet.
- Публічні ринкові дані для demo беруться з mainnet; hook-запобіжник, що забороняє агенту прямі звернення до mainnet-адрес, не змінюється (код бота бере адреси з конфігу).
