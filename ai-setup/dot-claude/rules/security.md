# Безпека (ТЗ §14)

- Ключі біржі — лише право торгівлі. При збереженні ключа перевіряються дозволи через API; ключ із правом виводу **відхиляється**.
- Шифрування ключів — AES-256-GCM, унікальний nonce на запис, `ENCRYPTION_KEY` з `.env`. Розшифрування лише на момент підпису запиту.
- Секрети не потрапляють у логи, винятки (`repr`), API-відповіді, UI. Використовуй `SecretStr`.
- Live- та Testnet-ключі зберігаються окремо; режим фіксується при створенні бота.
- Локальний API: `127.0.0.1`, bearer-токен, перевірка `Origin`/`Host` (захист від DNS rebinding і CSRF), суворий CORS.
- Небезпечні дії пишуться в `audit_log` з причиною та підтвердженням.
- `.env` ніколи не комітиться і не читається агентом; приклад — у `.env.example` без реальних значень.
- Docker: БД публікується лише на `127.0.0.1:5432`.
